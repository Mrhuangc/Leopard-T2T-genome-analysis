# OR plotting commands

Run from the repository root after setting `OR_ROOT`, `OR_DATA_ROOT` and `OR_RESULT_ROOT` as in [README.md](README.md). Commands read external tables and write to the selected result directory. Table schemas are listed in [`config/input_schemas.tsv`](config/input_schemas.tsv); paths there follow the original OR package layout.

## Figure 5A: chromosome distribution

Place the three Ppa chromosome-length, locus and cluster tables under `$OR_DATA_ROOT/fig5a/figure/Ppa_OR_cluster_landscape_main_v1/`.

```bash
Rscript "$OR_ROOT/03_main_figure/fig5a_chromosome_distribution/plot_fig5a_pardus_or_chromosome_distribution.R" \
  "$OR_DATA_ROOT/fig5a" "$OR_RESULT_ROOT/figure/fig5a"
```

## Figure 5B: subfamily composition

`$OR_DATA_ROOT/fig5b/` contains `species_OR_subfamily_counts.tsv`, `species_metadata.tsv` and the assignment stage's `ASSIGNMENT_COMPLETE.json`. The count script produces the primary high/medium tables and sensitivity tables including low-confidence assignments. The supplied topology heatmap wrapper plots the sensitivity tables.

```bash
FIG5B="$OR_ROOT/03_main_figure/fig5b_subfamily_composition"
Rscript "$FIG5B/analysis/OR_subfamily_comparison_v1_20260903/build_fig5b_subfamily_count_data.R" \
  "$OR_DATA_ROOT/fig5b" "$FIG5B/figure/OR_subfamily_comparison_final"
(cd "$FIG5B" && Rscript analysis/OR_subfamily_phylogeny_heatmap_20260908/run_fig5b_subfamily_phylogeny_heatmap.R)
```

The heatmap wrapper writes figures under `figure/OR_subfamily_comparison_phylogeny_v1_20260908/` in the Figure 5B module directory.

## Figure 5C: OR6C micro-synteny

Prepare the external project tree under `$OR_DATA_ROOT/fig5c/`:

```text
analysis/OR6C_synteny_audit_v1_20260902/derived_v2/OR6C.structural_events.min50bp.tsv
analysis/OR_subfamily_comparative_v1_20260902/locus_OR_subfamily_genomic_context.tsv
analysis/OR_multispecies_20260825/source/Ppa/11_complete_OR_catalog/Ppa.complete_OR_catalog.tsv
analysis/OR_multispecies_20260825/source/Ppa_or/11_complete_OR_catalog/Ppa_or.complete_OR_catalog.tsv
out_check/extracted_intervals.tsv
out_check/Ppa_vs_Ppa_or.OR6C.asm5.detailed.v2.paf
```

The interval and detailed PAF files come from the OR6C extraction/alignment stage; the plotting input retains its `v2` filename.

```bash
Rscript "$OR_ROOT/03_main_figure/fig5c_or6c_micro_synteny/analysis/OR6C_synteny_audit_v1_20260902/figure_v1/plot_fig5c_or6c_cluster_synteny.R" \
  "$OR_DATA_ROOT/fig5c" "$OR_DATA_ROOT/fig5c/out_check" "$OR_RESULT_ROOT/figure/fig5c"
```

## Figure S37: HiFi junction evidence

`$OR_RESULT_ROOT/figs5/input_snapshot/` contains `coverage_summary.tsv`, `event_evidence_summary.tsv`, and for each of `OR6C_INS17kb` and `OR6C_INS27kb`, `<event>.direct_primary_MAPQ20.tsv` and `<event>.MAPQ20.depth.tsv.gz`. Depth files are headerless three-column SAMtools tables: contig, 1-based position, depth.

```bash
Rscript "$OR_ROOT/04_supplementary_figures/figs5_or6c_hifi_validation/scripts/plot_figs5_or6c_hifi_junction_validation.R" \
  "$OR_RESULT_ROOT/figs5"
```

This writes `figure/`, `table/` and `qa/` beneath the supplied analysis directory.

## Figure S38: chromosome-region alignments

The external input directory contains `panel_a_filtered_primary_blocks.tsv` and `Ppa_vs_felids.macro_synteny.summary.tsv`. The summary is generated by the macro-synteny workflow; the block table contains primary blocks filtered at 10 kb, 90% identity and MAPQ 20. Its coordinate columns are listed in the schema inventory.

```bash
S6="$OR_ROOT/04_supplementary_figures/figs6_chrd1_macrosynteny"
Rscript "$S6/plot_figs6a_macro_alignment.R" "$OR_DATA_ROOT/figs6" "$OR_RESULT_ROOT/figure/figs6"
Rscript "$S6/plot_figs6b_regional_homology.R" "$OR_DATA_ROOT/figs6" "$OR_RESULT_ROOT/figure/figs6"
python "$S6/assemble_figs6_panels.py" --panel-dir "$OR_RESULT_ROOT/figure/figs6"
```

## Supporting copy-number analysis

```bash
COPY="$OR_ROOT/05_supporting_analysis/or_subfamily_copy_number/scripts"
ASSIGN_OUT="$OR_RESULT_ROOT/OR_subfamily_tree_assignment_v1"
python "$COPY/build_or_subfamily_copy_number_matrix.py" \
  --representatives "$ASSIGN_OUT/source_outputs/representative_OR_subfamily_assignments.tsv" \
  --locus-map "$OR_DATA_ROOT/joint/functional_OR_identical_sequence_map.tsv" \
  --species-metadata "$OR_ROOT/config/species_metadata.tsv" \
  --previous-locus-table "$ASSIGN_OUT/source_outputs/locus_OR_subfamily_assignments.tsv" \
  --output-dir "$OR_RESULT_ROOT/copy_number"
```

For the absolute-count heatmap, place `absolute_heatmap_top30.source_data.tsv` and `species_metadata.tsv` in the selected plotting-input directory:

```bash
Rscript "$COPY/plot_or_subfamily_absolute_copy_number_heatmap.R" \
  "$OR_DATA_ROOT/copy_number_heatmap" "$OR_RESULT_ROOT/figure/copy_number"
```
